# Vercel Chat Implementation Plan

**Goal:** Prepare a Redis-backed Vercel deployment without changing the chat UI.

**Architecture:** Export a Node HTTP server from api/index.js. Initialize the
Redis adapter before accepting Socket.IO connections. Derive room presence from
live sockets across instances and keep browser reconnects on WebSocket transport.

**Tech Stack:** Node 24, Express, Socket.IO 4, Redis, Mocha.

**Spec:** ../specs/2026-11-15-vercel-design.md

## Constraints

- Preserve anonymous, ephemeral chat; no message history or authentication.
- Require REDIS_URL and REDIS_CHANNEL_PREFIX on Vercel.
- Keep local development possible without Redis.
- No remote push or deployment without a user request.

## Review Focus

Malformed event payloads, reconnects, room changes, Redis initialization failure,
and room isolation must not crash the process or leak messages across rooms.

## Tasks

1. Add failing integration tests for exports, joins, validation, presence,
   disconnects, and isolation. Update runtime and dependencies; run the tests.
2. Implement the server factory, Redis initialization, Vercel entry point and
   routing. Run the integration tests, including cross-instance Redis when a
   local Redis server is available.
3. Update browser transport/error handling and deployment documentation.
   Run the complete suite, inspect the diff, and package the prepared repository.

## Execution Record

- Design approved in chat. Implementation runs locally without delegation.
- New integration tests initially failed because the server factory was absent.
- Final Node 24 verification passed all 20 tests, including real Redis
  cross-instance chat, environment isolation, and fail-closed outage handling.
- Review caught a test listener race: an earlier join update could be mistaken
  for a disconnect update. Presence assertions now wait for the expected list.
- Compatible security remediation was attempted; five development-only Mocha
  advisories remain. No forced dependency overrides were added.
- Production audit returned zero vulnerabilities; syntax and diff checks passed.
- Temporary Redis container stopped and removed after verification.
